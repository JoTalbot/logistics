## Compliance/security
`TG_API_ID`, `TG_API_HASH` and the Telethon session are runtime secrets. Telegram's current API/content terms restrict scraping/aggregation and AI/ML use of platform data, so this implementation deliberately uses deterministic local parsing and does not introduce an LLM into the ingestion path. Source-specific permissions and applicable law must be verified before production operation.
