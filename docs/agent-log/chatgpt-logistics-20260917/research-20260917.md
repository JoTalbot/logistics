## External research
- Linux kernel cgroup v2 documentation: https://docs.kernel.org/admin-guide/cgroup-v2.html
  - delegated subtrees are containment boundaries for the delegatee;
  - `cgroup.kill` terminates the cgroup subtree and handles concurrent forks/migrations;
  - delegation requires the relevant filesystem permissions and is not established merely by the existence of a cgroup directory.
- systemd resource-control documentation: `Delegate=` permits an unprivileged service to create a subhierarchy beneath its service cgroup, but actual deployment behavior still requires target-host verification.
- Repository evidence contract requires the effective identity to be the dedicated non-root `logistics-agent` identity and requires successful destructive rehearsal before runtime activation.
