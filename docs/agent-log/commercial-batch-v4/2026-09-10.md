# Commercial Automation Batch V4 — 2026-09-10

## Scope
Advance market intelligence from a current observation snapshot to durable historical evidence, deterministic route economics and an explicit human-review boundary.

## Implemented

- Added `market_observation_history` as append-only historical provider snapshots.
- Hardened market-observation upsert so stale observations cannot overwrite newer current state.
- Added freshness checks and explicit verified-field extraction. Canonical route/country/cargo/weight/price fields must be allowlisted by an integration contract.
- Added deterministic route economics: direct cost, risk reserve, clean profit, risk-adjusted profit and margin rate.
- Added historical market-price trend bucketing and conservative recommended-price calculation.
- Added durable `review_audit` records.
- Added explicit human review service for publication intents and negotiation sessions.
- Added authenticated review API using `REVIEW_OPERATOR_TOKEN`; review approval never performs an external provider call.
- Fixed Docker Compose fresh-database initialization to include the complete migration chain, including duplicated historical migration sequence numbers through deterministic destination aliases.
- Added unit and PostgreSQL integration coverage for freshness, historical idempotency, verified-field extraction, route economics, trends and review validation.
